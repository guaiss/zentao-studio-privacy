Sidepad 1.3.1 — Foreground service

Package: com.zentaostudio.floatingpaddemo. This native screen recording shows the signed release on Android 16.

Open video directly

  1. The user taps Start bubble in Sidepad. Its activity moves into the background and a persistent visible bubble appears.
  2. The user chooses Start recording. This opens the user's keyboard; Sidepad itself does not record audio. The user types a note into the editor above the keyboard.
  3. The user expands the editor, dismisses the keyboard, opens and folds the quick panel.
  4. The user selects Stop bubble. The overlay and its foreground service stop.
  5. The saved note remains in Sidepad.

The session is explicitly started by the user and stays perceptible via its overlay and foreground notification. It cannot be deferred without losing the immediately requested editor; interrupting it removes the input surface and disconnects the current keyboard session. Notes are saved locally. No microphone, screen capture, accessibility or network permission is requested by Sidepad. No scheduled or boot start is used. Overlay and notification permissions were already granted in the test setup.

No account or payment is required. On a fresh install, finish the two-page introduction, tap Start bubble, grant display-over-other-apps access, then tap Start bubble again. Notifications are optional. Stop from the bubble menu, app or service notification.
