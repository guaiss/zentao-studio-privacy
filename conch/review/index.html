Package: com.zentaostudio.conch

This native Android screen recording demonstrates an interactive SSH session started by the user, continued while switching apps, and explicitly disconnected. The SSH connection is to a disposable local test fixture; the video is demonstration evidence, not a public review server.

Conch uses a foreground service only while user-initiated SSH sessions remain open. The ongoing notification provides a Disconnect all action. Delaying or interrupting the service would interrupt the user's interactive connection; it stops when the last session is closed. The app does not start SSH sessions at boot or on a schedule.

Core SSH and SFTP features require no Conch account or payment. Add a host you control and connect with your usual SSH credentials. Optional Pro adds extra terminal color palettes.
